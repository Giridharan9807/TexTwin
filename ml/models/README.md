# Models Directory

This folder houses the model parameters, weights, checkpoints, and export files.

## Structure

- **`trained/`**: Finalized models optimized and validated for production deploy.
- **`checkpoints/`**: Intermediate state dumps, weights, and epochs stored during training.
- **`exported/`**: Serialized inference versions of models (e.g., ONNX, pickle, Joblib, or TensorFlow SavedModel).
