# Dataset Directory

This folder contains the telemetry and health datasets used for training and evaluating TexTwin machine learning models.

## Structure

- **`raw/`**: Raw telemetry logs and event records gathered from physical and simulation sensors.
- **`processed/`**: Cleaned, imputed, and scaled feature matrices ready for model training.
- **`synthetic/`**: Artificially generated datasets used for what-if scenarios, edge case simulations, and dry-run tests.
